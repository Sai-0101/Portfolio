## ⚡ Key Highlights & Features

### 🖥️ Interactive Terminal Boot Loader
- **System Initialization:** Realistic terminal diagnostics screen simulating local hardware checks, system specs, and environment initialization before mounting the UI.
- **Skip & Audio Triggers:** Smooth transition from CLI diagnostic mode directly into ambient canvas mode.

### 🩸 Blood-Moon Hero & Orbiting Gem Navigation
- **Dynamic Centerpiece:** Framed circular blood-moon aesthetic featuring custom animated avatar poses and ambient visual shaders.
- **Orbiting Interactive Gems:** Floating, reactive gem nodes (Certificates, Social Coordinates, Project Archives) rotating along defined orbital paths that respond to hover state, pointer proximity, and click triggers.

### 🏛️ "Technologies I Know" — 3D Round Table Conference
- **Interactive Delegation Table:** Real-time 3D interactive roundtable featuring dedicated technology delegates:
  - **Systems & Performance:** C++ (C++17/20, STL Architecture)
  - **Modern Web Architecture:** HTML5, CSS3, Tailwind CSS, JavaScript (ESNext)
  - **Game Development & Physics:** Unity Engine, C#, Frame Data & Hitbox Mechanics
  - **Applied AI & Tooling:** Python, Local LLMs (Ollama, LM Studio, NPU Acceleration)

### 🏆 Hackathon & Competitive Track Records
Dedicated interactive timeline and cards highlighting competitive builds and national hackathon selections:
- **Inkloom AI Challenge:** *BrandPulse AI* (Enterprise Brand Governance & Accessibility Engine)
- **Bit N Build 2026:** Maharashtra State Hackathon Finalist Prototype
- **CodeNexus India 2026:** National Engineering Hackathon Prototype
- **AgentVerse 2026:** Autonomous AI Agents Hackathon by HackIndia
- **Hackatopia 2026:** Multi-disciplinary Project Prototype

### 🚀 Core Engineering Projects Showcase
- **BrandPulse AI:** Enterprise content moderation and brand rule compliance pipeline.
- **Vitometer:** Interactive digital logic verification web platform implementing active-low Boolean circuit processing.
- **2D PvP Silhouette Fighter:** Physics-driven, competitive 1v1 combat prototype built with precise hurtbox/hitbox registration and custom pixel-art animation frames.
